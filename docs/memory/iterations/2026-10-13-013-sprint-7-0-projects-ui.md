# Iteration 013 — Спринт 7-0: UI «Проекты» (brief → ICP → sourcing)

Дата: 2026-10-13
Коммит: a373396

## Цель
Закрыть разрыв с хотелкой заказчика: дать пользователю через Web UI создать проект, ответить на
уточняющие вопросы, увидеть ЦА/сегменты и поиски — без API/терминала.

## Изменения
- **`/projects`** — список проектов (брифов) + диалог «Новый проект» (свободный текст/ссылка).
- **`/projects/[id]`** — вводные, уточняющие вопросы (LLM) с ответами, «Завершить бриф»,
  блок **ЦА (ICP + сегменты)**, блок **Поиски** (search jobs), прогресс-степпер Бриф→ЦА→Поиск.
- **Sidebar:** пункт «Проекты».
- Хуки: `use-projects.ts` (список/создание/вопросы/complete/ICP/поиски).
- Всё поверх готовых API через BFF-прокси (`briefs`/`icps`/`sourcing` уже замаплены).

## Решения
- **Проект = бриф**, не тенант (подтверждено данными: 91 тенант / 135 брифов, до 5 брифов на тенант).
- **Тенанты в UI не создаём** — это Спринт 7A (`POST /auth/register`), чтобы не конфликтовать.

## Тесты / проверки
- E2E через UI: создать проект → вопросы → ответы → complete → авто-ICP (3 сегмента) → авто-sourcing → flow running.
- `pnpm typecheck` — зелёный; ruff/mypy (403)/pytest (162) — зелёные; healthcheck 18 OK.
