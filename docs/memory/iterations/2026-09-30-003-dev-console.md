## Goal

Прозрачность окружения: единое место, где видно здоровье сервисов, тенантов, события NATS
и данные (компании/контакты/брифы/stop-list) — без ручных скриптов и jq.

## Changes

- `services/dev-console/` — FastAPI-сервис: прокси к бэкендам + read-only чтение JetStream + HTML.
- `infra/docker-compose.dev.yml` — сервис dev-console (порт 48110).
- Эндпоинты: `/api/services`, `/api/tenants`, `/api/streams`, `/api/events`, `/api/data/{companies,contacts,briefs,stoplist}`.

## Notes
- Список всех тенантов через API невозможен (RLS: роль `outreach_app` видит только свой тенант).
  Консоль как dev-инспектор читает список тенантов read-only из Postgres отдельным admin-DSN
  (`DATABASE_URL_ADMIN`). Это осознанное исключение только для dev-инструмента.


- Консоль НЕ ходит в БД напрямую — только через API сервисов (tenant header прокидывается).
- NATS-события читаются одноразовым consumer, который сразу удаляется (стримы не модифицируются).
- Всё read-only кроме создания тенанта.
